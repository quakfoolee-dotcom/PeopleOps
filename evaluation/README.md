# Evaluation

The versioned gold suite is `gold_cases.json`. It contains 25 synthetic cases defined before retrieval, MCP, and agent behavior are implemented. The fixed evaluation date is **2026-09-01**, matching the policy corpus effective date.

The suite covers straightforward policy questions, multi-document questions, employee/tool workflows, clarification, escalation, privacy, out-of-scope handling, and confirmation safety. Each case records observable facts, exact policy sections, required and forbidden tools, expected outcome, answer constraints, and safety behavior.

Machine-readable JSON Schemas are committed under `schemas/`. See `docs/data-contracts.md` for the contract reference, validation commands, and case-authoring guide.

Phase 5 adds the retrieval-only ablation under `results/`: dense `k=5`, hybrid `k=5`, and hybrid
`k=8` over the 24 cases that declare 48 policy-section expectations. It does not by itself claim
final-answer, tool-selection, workflow, safety, or deployed-latency results; the Phase 10 report
combines it with the complete execution metrics and separate cold/warm measurements.

Phase 6 adds `results/phase6_mcp_validation.json`, generated by
`python scripts/evaluate_mcp_tools.py --write`. It records discovery and schema counts, one traced
successful call per tool, confirmation refusal, idempotent repeat behavior, token absence from
traces, and unchanged committed ticket fixtures.

Phase 7 adds `results/phase7_workflows.json`, generated by
`python scripts/evaluate_workflows.py --write`. It records three repeat runs for remote-work and PTO,
the expense backup, bounded tool paths, input clarification, unavailable-service and policy-conflict
behavior, and the confirmation-gated idempotent mock-ticket sequence. It is a focused phase exit
evaluation; the complete 25-case metric run remains Phase 10.

Phase 10 adds `results/phase10_gold_evaluation.json` and `.csv`, generated by
`python scripts/evaluate_gold.py --write`. The real orchestrator executes all 25 cases through MCP,
RAG, synthetic data, safety gates, and the deterministic CI provider. The committed run reports
100% expected-fact accuracy, answer-constraint adherence, claim support, groundedness, citation
accuracy and coverage, tool selection, workflow completion, clarification/escalation accuracy,
action safety, and primary-demo completion. Both primary workflows also pass ten consecutive warm
runs. See `docs/phase10-evaluation-submission.md` for methodology and error analysis.

Phase 10 also commits four focused evidence sets:

- `answer_checks.json` makes every expected fact and answer constraint executable and declares its
  policy-citation or structured-tool support;
- `intent_cases.json` and `results/phase10_intent_robustness.json` cover 15 paraphrase, typo,
  alias, mixed-intent, adversarial-bypass, and unsupported-scope cases at 100%;
- `results/phase10_embedding_comparison.json` compares feature-hash and
  `all-MiniLM-L6-v2` direct dense retrieval on the identical corpus and gold evidence;
- `results/phase10_hosted_provider.json` records three generic read-only production observations,
  provider acceptance/fallback and latency, plus 100% workflow/citation/tool/no-write integrity.

Reproduce or validate the current evidence from the repository root:

```powershell
python scripts/evaluate_rag.py --write
python scripts/evaluate_mcp_tools.py --write
python scripts/evaluate_workflows.py --write
python scripts/evaluate_intents.py --write
python scripts/evaluate_gold.py --write
python scripts/evaluate_embeddings.py --check
python scripts/evaluate_hosted_provider.py --check
```

The neural artifact is regenerated only in the optional `neural-eval` environment. The hosted
artifact is collected only with explicit production access; ordinary CI performs offline artifact
validation and never requires a provider secret.

`results/phase10_hosted_latency.json` separately records the exact-release production smoke and an
immediate warm recheck, including health/root/chat timing, provider-attempt count, resolved model,
and retained GitHub Actions evidence links.
